# Viva Questions and Short Answers

1. **What is deep learning?**  
   Deep learning is a branch of machine learning that uses neural networks with multiple layers to learn patterns from data.

2. **What is NLP?**  
   Natural Language Processing is a field of AI that helps computers process and analyse human language.

3. **What is tokenization?**  
   Tokenization converts text into tokens, such as words, which can then be represented numerically.

4. **Why do we use padding?**  
   Padding makes input sequences the same length so they can be processed together by the model.

5. **What is an embedding layer?**  
   It maps word IDs to trainable numeric vectors that represent words in a learned space.

6. **What does softmax do?**  
   Softmax converts output scores into values that sum to 1, commonly interpreted as class probabilities.

7. **What is overfitting?**  
   Overfitting occurs when a model learns training examples too closely and performs poorly on unseen data.

8. **Why is the dataset small?**  
   It is a starter dataset for learning the workflow. A real application would need a much larger, carefully collected dataset.

9. **Can the system read someone's mind?**  
   No. It only predicts the category suggested by the words entered.

10. **What is Streamlit?**  
    Streamlit is a Python framework for building simple interactive web apps.

11. **What is a training set?**  
    The training set is the data used to adjust the model's parameters.

12. **What is a validation set?**  
    A validation set helps monitor performance on data not used for direct parameter updates.
